# Muzyka tła

Włóż ścieżki MP3 do tego katalogu pod nazwami:

- `menu.mp3` — muzyka menu głównego i wyboru talii.
- `match.mp3` — muzyka podczas meczu.

Odtwarzacz zapętla każdą ścieżkę i przełącza ją automatycznie wraz z ekranem.
Wspierany jest MP3, tak jak wbudowane efekty dźwiękowe. Oba pliki dostarczone do
projektu zostały już przypisane do powyższych nazw.
